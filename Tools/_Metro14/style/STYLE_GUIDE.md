# Metro-14: стайлгайд спрайтов

Собран по реальным RSI в `Resources/Textures/_Metro14` (260 RSI). Референс по стилю: `_Stalker` из stalker-14.

## 1. Цвета
- Палитра: `metro14_palette.png` / `metro14_palette.hex`, 48 самых частых цветов Structures и Objects. Основа: тёмно-серые `#181818`–`#484840`, тёплая ржавчина и коричневые `#403020`, `#584028`, `#402010`, приглушённые синие `#202838`. Яркий цвет только как маленький акцент, например красная повязка или огонь.
- Лимит цветов на один state. Это медиана по игре, верхнюю границу превышать нельзя:
  - предметы 32×32: 8–16;
  - структуры 32–64: 12–30;
  - крупные структуры 96–128: до ~300 на весь лист (у `train.png` 272).
- Запрещено: сглаживание, градиенты, генерация картинки с последующим сжатием. Полупрозрачность допустима только у стёкол, теней, света и оверлеев (белый список state). У корпуса и краёв её быть не должно. Для примера: в текущем `vaz2104_wreck.png` 12 766 цветов и 1 188 полупрозрачных пикселей, у `train.png` 272 цвета и 0 полупрозрачных.

## 2. Контур и свет
- Внешний контур в 1 px, тёмный: `#101010`–`#303030`. Чистый `#000000` редко.
- Внутренние линии на 1–2 тона темнее заливки, не чёрные.
- Свет сверху-слева. Тень в 2–3 чётких ступени: хайлайт, основной тон, тень, глубокая тень. Без дизеринга по всей площади.
- Износ, то есть ржавчина, сколы и грязь, рисуется отдельными читаемыми пятнами, а не шумом.

## 3. Размер и масштаб
- Кадр по категории. Сначала смотри на соседей в той же папке:
  - Clothing, Objects: 32×32;
  - Structures: 32×32 или 64×64, крупные 96 и выше (`train` 96×96);
  - Mobs: 64×64, 64×32.
- 1 тайл = 32 px. Объект должен быть реального размера в тайлах. Машина около 3×1.5 тайла.

## 4. Направления и файлы
- 4-dir — это сетка 2×2: сверху S|N, снизу E|W. PNG = 2×размер кадра (128 → 256×256). Горизонтальная полоса не используется.
- `meta.json` копируется с соседа и правится. Обязательно `"version": 1`, `license`, `copyright`, `size`, `states`.
- Путь по типу объекта: машины и крупный декор в `Structures/`, мелкий декор в `Structures/Decoration/`. Перед сдачей ищется похожий объект в репо, и путь берётся у него.
- В прототипе нельзя `snapCardinals: true` на 4-dir state, это ведёт к вылету `DebugAssert` при спавне. `Icon` ставится только на state без направлений.

## 5. Процесс сдачи
1. 3–5 рефов из `_Metro14` или `_Stalker` того же типа и размера.
2. Силуэт без деталей, Игорь говорит «ок».
3. Детали, рисуются руками по сетке.
4. Доска сравнения: новый спрайт рядом с рефами на тёмном тайле, 1× и 4×.
5. Валидатор Metro Code (`Tools/`): размер, сетка, states, пути, лимит цветов, полупрозрачность.
6. Style pass по доске, затем живой спавн QA, затем Игорь.
